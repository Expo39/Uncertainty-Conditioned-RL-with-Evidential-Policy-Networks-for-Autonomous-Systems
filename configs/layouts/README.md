# configs/layouts/

Pre-computed parking lot geometry files. Generated by `make generate-layouts` from the
floor plan modules in `scripts/layouts/floor_plans/`. **Never edit these files by hand** -
regenerate from source after any change to a floor plan module.

## Files

| File | Purpose |
|------|---------|
| `rectangle.yaml` | Rectangular lot with 7 left-wall perpendicular bays, centred cluster (12 perp + 8 angled), 12 bottom perpendicular, 7 bottom angled, 6 right-wall angled, 2 motorcycle bays. Total 54 bays (training) |
| `trapezoid.yaml` | 39-bay trapezoid lot (training) |
| `irregular_a.yaml` | 58-bay irregular polygon lot (OOD evaluation only) |
| `flat_plane.xodr` | OpenDRIVE world definition for the FlatPlane CARLA map |

## Regenerating

```bash
make generate-layouts                      # All three layouts
make generate-layouts LAYOUT=rectangle     # Single layout
```

Output: `configs/layouts/<name>.yaml` + `outputs/layouts/<name>.png` (bird's-eye preview).

## YAML schema

Each layout YAML has the following top-level keys (all in CARLA world frame):

| Key | Type | Description |
|-----|------|-------------|
| `corners` | list of `{x, y}` | Lot perimeter polygon vertices (CCW) |
| `bays` | list of bay dicts | All parking bays |
| `spawn` | `{x, y, yaw}` | Primary spawn transform |
| `extra_spawns` | list of `{x, y, yaw}` | Additional spawn transforms |
| `patrol_waypoints` | list of `{x, y}` | NPC patrol path waypoints |
| `pedestrian_zones` | list of `{x_min, x_max, y_min, y_max}` | Pedestrian spawn areas |
| `obstacles` | list of `{x_min, x_max, y_min, y_max}` | Interior obstacle rectangles (optional) |

Each bay dict:

| Key | Type | Description |
|-----|------|-------------|
| `x`, `y` | float | Bay centre in CARLA world frame |
| `yaw` | float | Bay heading (deg, CARLA CW convention) |
| `width`, `depth` | float | Bay dimensions (m) |
| `bay_type` | str | `"perpendicular"`, `"angled"`, or `"parallel"` |
| `always_empty` | bool | If true, never occupied by a parked vehicle |
